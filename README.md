Function
1. Add
The function add was defined so when you input two numbers (a,b), it adds the numbers a and b. Use it by calling add(a, b) and pick a number for a and b. 

Example: 
test = add(5,3) 
print(test)

Output: 8

2. Substract
The function substract was defined so when you input two numbers (a,b), it substracts b from a and returns the difference. This function breaks when one or both of the inputs consist of a string or an undefined variable

Example: 
test = substract(5,3) 
print(test)

Output: 2 

3. Multiply 
multiply(a, b) gives the product of a and b.


Extension functions

distance_from_zero(x) uses the substract function to calculate the distance between the input x and 0.
